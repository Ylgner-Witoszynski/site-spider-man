# Spider-Man: Um Novo Dia

Landing page conceitual inspirada no universo do Homem-Aranha, criada como projeto de estudo de desenvolvimento front-end e animações para a web.

## Prévia

![Prévia do projeto](assets/bg.webp)

## Sobre o projeto

A página apresenta uma experiência visual inspirada em um site de divulgação de filme, com:

- seção de abertura com trailer e conteúdo sobre Peter Parker;
- animações ligadas à rolagem da página;
- sequência de imagens que acompanha a navegação;
- seção interativa para apresentação do elenco;
- layout adaptável a diferentes tamanhos de tela.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- [GSAP](https://gsap.com/) e plugins ScrollTrigger, ScrollSmoother e SplitText

As bibliotecas GSAP e a fonte Poppins são carregadas por CDN. É necessária uma conexão com a internet para esses recursos externos.

## Como executar

O projeto é estático e não precisa de instalação de dependências nem de etapa de build.

1. Baixe ou clone o repositório.
2. Abra a pasta `Site Spider-man` no Visual Studio Code.
3. Abra o `index.html` diretamente no navegador ou use uma extensão de servidor local, como o Live Server.

Mantenha a pasta `assets` junto aos arquivos HTML, CSS e JavaScript para que as imagens, o trailer e as animações sejam carregados corretamente.
